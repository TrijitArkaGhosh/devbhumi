# DevBhumi লাইভ করার গাইড (বিনামূল্যে)

পুরোটা তিন ধাপে হয়: Render-এ সাইট চালু করা, একটা সার্ভিস দিয়ে সাইটকে সবসময় জাগিয়ে রাখা, আর (চাইলে) আসল WhatsApp যুক্ত করা।
কোডে কোনো গোপন কোড রাখা হয় না; সেগুলো শুধু Render-এর **Environment** সেটিংসে থাকে।

## ধাপ ১ · Render-এ সাইট চালু করা (১০ মিনিট)

1. https://render.com খুলে **Get Started** → **GitHub** দিয়ে সাইন-ইন করুন (কার্ড লাগবে না)।
2. ড্যাশবোর্ডে **New +** → **Blueprint** বাছুন।
3. GitHub-এর `devbhumi` রিপোজিটরি বেছে **Connect** করুন। Render নিজেই `render.yaml` পড়ে নেবে।
4. `DEVBHUMI_BASE_URL` আপাতত ফাঁকা রেখে **Apply** চাপুন। কয়েক মিনিটে সাইট চালু হবে, ঠিকানা হবে প্রায় এরকম: `https://devbhumi.onrender.com`
   (নামটা খালি না থাকলে Render শেষে কয়েকটা অক্ষর জুড়ে দেয়।)
5. সাইট চালু হলে **Environment** খুলে `DEVBHUMI_BASE_URL` = আপনার পুরো ঠিকানা (যেমন `https://devbhumi.onrender.com`) বসিয়ে **Save** করুন।
6. পরীক্ষা: `https://<আপনার-ঠিকানা>/healthz` খুললে `{"ok": true, ...}` দেখাবে।

**গোপন কোড কোথায় পাবেন:** Render → আপনার সার্ভিস → **Environment**। সেখানে
`ADMIN_TOKEN` (ব্যাজ ছাপানোর পাতা), `MITRA_TOKEN_BARDHAMAN` (পথিক মিত্র রিয়া), `MITRA_TOKEN_KALNA` (পথিক মিত্র অরূপ)।
এগুলো শুধু টিমের মধ্যে রাখুন; চ্যাটে, ডকুমেন্টে বা GitHub-এ কখনো লিখবেন না।

## ধাপ ২ · সাইটকে কখনো ঘুমোতে না দেওয়া (৫ মিনিট)

Render-এর ফ্রি সাইট ১৫ মিনিট কেউ না খুললে ঘুমিয়ে পড়ে। প্রতি ১০ মিনিটে একবার খুলিয়ে রাখলে আর ঘুমোয় না।

1. https://cron-job.org (অথবা https://uptimerobot.com) এ ফ্রি অ্যাকাউন্ট খুলুন।
2. নতুন কাজ (Create cronjob / Add monitor) বানান:
   - ঠিকানা: `https://<আপনার-ঠিকানা>/healthz`
   - সময়: **প্রতি ১০ মিনিট** (Every 10 minutes)
3. সেভ করুন। Render মাসে ৭৫০ ঘণ্টা ফ্রি দেয়, তাতে একটা সাইট পুরো মাস চালু থাকে।

মনে রাখবেন: কোড আপডেট হলে বা Render সার্ভার রিস্টার্ট করলে সাইট আবার নমুনা তথ্য দিয়ে শুরু হয়। ডেমোর জন্য এটাই ভালো।

## ধাপ ৩ · লাইভ ঠিকানার ব্যাজ ছাপানো

1. `https://<আপনার-ঠিকানা>/#/badges` খুলুন, `ADMIN_TOKEN` দিয়ে সাইন-ইন করুন।
2. ঠিকানার ঘরে লাইভ ঠিকানাটাই বাছা আছে কি না দেখে **ব্যাজ ছাপুন** চাপুন।
3. আগের (ল্যাপটপে ছাপানো) ব্যাজ লাইভ সাইটে কাজ করবে না, কারণ ঠিকানা আর গোপন কোড বদলেছে।
4. DPR-এর কভারের ফাঁকা বাক্সে লাইভ ঠিকানার QR বসান (আমাকে ঠিকানাটা জানালে QR বানিয়ে দেব)।

## ধাপ ৪ · আসল WhatsApp (ঐচ্ছিক, ৩০–৪৫ মিনিট)

সাইটের ভেতরের WhatsApp ডেমো এটা ছাড়াই চলে। আসল WhatsApp নম্বরে চ্যাট দেখাতে চাইলে:

1. https://developers.facebook.com এ Facebook অ্যাকাউন্ট দিয়ে লগ-ইন → **My Apps** → **Create App** → ধরন **Business** → WhatsApp যোগ করুন।
2. **WhatsApp → API Setup** পাতায় Meta একটা **পরীক্ষার নম্বর** দেয়। সেখানে **To** অংশে টিমের ২–৫টা ফোন নম্বর যোগ করে যাচাই করুন
   (শুধু এই নম্বরগুলোতেই পরীক্ষার নম্বর থেকে উত্তর যায়)।
3. Render-এর **Environment**-এ বসান:
   - `WHATSAPP_TOKEN` = API Setup পাতার Access token (স্থায়ী টোকেনের জন্য System User টোকেন বানানো ভালো; অস্থায়ী টোকেন ২৪ ঘণ্টায় শেষ হয়)
   - `WHATSAPP_PHONE_ID` = Phone number ID
   - `DEVBHUMI_WA_NUMBER` = পরীক্ষার নম্বরটা, শুধু অঙ্কে (যেমন `15551234567`)
   - `WHATSAPP_APP_SECRET` = App settings → Basic → App secret
4. **WhatsApp → Configuration → Webhook**:
   - Callback URL: `https://<আপনার-ঠিকানা>/webhook/whatsapp`
   - Verify token: Render-এর `WHATSAPP_VERIFY_TOKEN`-এর মান
   - **Verify and save**, তারপর **messages** ফিল্ডে Subscribe।
5. যাচাই করা ফোন থেকে পরীক্ষার নম্বরে `Hi` পাঠান। DevBhumi-র মেনু উত্তর আসবে; `BDN-0108` লিখলে ভোলা দাসের কার্ড আসবে।

খরচ: কেউ নিজে মেসেজ করলে ২৪ ঘণ্টার মধ্যে আমাদের উত্তর মাসে প্রথম ১,০০০টা পর্যন্ত বিনামূল্যে (Meta-র নিয়ম বদলাতে পারে, শুরুর আগে দেখে নিন)।
